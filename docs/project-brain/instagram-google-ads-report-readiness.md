# Project Brain — Instagram Organic and Google Ads Report Readiness

## Independent decisions

Instagram Organic and Google Ads must never share one readiness result. Each channel may advance while the other remains blocked.

Both currently remain `uat_pending` in Connector, Job and Report catalogs. The audit never promotes a catalog itself.

## Instagram authority

Instagram Source completion is owned by the active Meta end-to-end continuation. This workstream may consume its accepted D1/Coverage/Lark evidence after completion but may not replay, repair or duplicate Meta execution. `meta_continuation_pending` remains a hard Instagram blocker.

## Google Ads authority

Code and signed transport are not sufficient. Promotion requires exact advertiser identity, completed signed delivery, replay/idempotency proof, non-empty Ads entity and daily facts, completed zero-failure Coverage, source parity, currency/timezone consistency and Ads SUM-before-ratio Report preview.

## Shared promotion gate

A channel is eligible for a separate promotion PR only after:

- exact identity accepted;
- Source UAT complete;
- Coverage complete with zero failures;
- source facts and required Lark parity complete;
- 1/3/7/30 Report settings and previews complete;
- null/N/A and observed-zero semantics verified;
- zero active Work/Lock and zero open terminal incident;
- all-false Worker and exact bindings verified;
- exact-head repository verification passed.

## Safety

The repository assessor reads sanitized evidence only. It performs no Provider request, signed-delivery replay, Queue action, D1/Lark mutation, Worker deployment, Catalog promotion, Schedule action or Production action.
