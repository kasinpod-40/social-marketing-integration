# 04 — API Discoveries

## Lark TikTok For Creator
Native integration can pull deeper organic analytics than basic TikTok Display API assumptions:
- Average video play duration
- Total video play duration
- Percentage watched completely
- Deduplicated viewers
- Traffic exposure sources
- Audience country/region breakdown

## Lark TikTok For Business
Fields observed are mainly configuration/master data:
- Campaign settings
- Ad group targeting/optimization settings
- Ad/creative metadata
- Spark post ID / video ID
- Pixel/application/offline event set references

Actual performance metrics were not observed in the provided fields.

## Lark Google Ads
Observed sources:
- Customer List
- Campaign List

Observed fields support audience/customer list and campaign configuration. Daily performance metrics were not observed.
