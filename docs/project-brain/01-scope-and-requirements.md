# 01 — Scope and Requirements

## Phase 1 scope
Collect and normalize social marketing data into Lark Base:

### Organic
- Facebook Organic
- Instagram Organic
- TikTok Organic
- YouTube Organic

### Paid Ads
- Meta Ads
- TikTok Ads
- Google / YouTube Ads

### System
- Lark Base tables
- Daily snapshots
- Sync logs
- System alerts
- AI summary reports to Lark group
- Project Brain

## Out of scope for phase 1
- Creating ads
- Editing campaigns
- Editing budget/bids
- Auto-optimization
- Full external dashboard
- TikTok Shop unless explicitly added later
- Product/revenue integration unless explicitly added later

## Estimate baseline
14 days is a PM estimate using 1 MD = 8 hours. Actual working time may exceed 8 hours/day, but the PM estimate should remain conservative.
